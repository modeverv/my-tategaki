MY-TATEGAKI / GUIDE

小説を書くためのマニュアル

Novel Studioで書き、章を見渡し、推敲して一冊へ。my-tategakiの利用案内。

縦書きで、小説を書く。
章を見渡し、一冊へ。

my-tategakiは、Emacsのテキスト原稿を縦書きのまま編集する道具です。Novel Studioでは、章の目次、表示設定、履歴、校正、作品資料、任意のローカルAI相談を同じ原稿から使えます。

プレーンテキスト章・節のアウトライン自由な原稿用紙EPUBを含む5形式
導入して最初の原稿を書く →Studioの画面と設定

最初は、書く・保存する・章を付ける

  1. Studioで原稿を開く

    M-x tategaki-studioを実行します。［新しい小説を書く］から始めるか、いま開いているテキスト原稿を使います。

  2. 読みやすい大きさへ調整する

    固定用紙やルビを表示する場合は、本文ウィンドウでM-x tategaki-typeset-editを実行します。［⚙設定］で文字サイズと原稿用紙を選びます。縦字数・列数を入力するか、固定寸法を使わないフリーにできます。

  3. 目次を横に置いて書く

    # 第一章、## 第一節のように見出しを書き、［目次］を開きます。章への移動も折りたたみもクリックで操作できます。

  4. 本文を保存する

    ［原稿］→［保存］、またはC-x C-s。履歴や設定の保存とは別に、本文のファイルを保存します。

目的から読む

WORKSPACE画面と設定を使う

Write／Review、ペインの閉じ方、作品情報、設定の保存先。

 EDITING入力と移動に慣れる

日本語IME、選択、検索、文字サイズ、Corfu・Copilotとの連携。

 TYPESETTINGルビと原稿用紙を整える

禁則、縦中横、自由な字数・列数、見開きと文字数。

 WRITING目次を見ながら推敲する

章・節のアウトライン、字下げ、脚本、辞書、ルール校正。

 HISTORY旧稿へ戻る・読み返す

履歴の別コピー復元、比較、前回位置、Reader、音読。

 LOCAL AIAIに相談する

Ollama／LM Studio、モデル選択、出典付き検索、資料コレクション。

 STORY NOTES人物と出来事を整理する

人物設定、時系列、伏線、話し方、読者と人物の知識差。

 EXPORTファイルへ書き出す

DockerでTXT・DOCX・PDF・EPUB・HTMLを生成する。

操作名を探す場合はコマンド・設定一覧、動かない場合は困ったときへ進んでください。上部の検索欄では日本語の用語とコマンド名の両方を検索できます。

本文と、補助情報を分けて保存する

入力・保存・Undo・コピー・検索は通常の原稿バッファに対して働きます。表示設定を変えても本文は変わりません。ルビ記法の挿入や字下げなど、実際に文字を追加する操作は通常の本文編集として保存されます。

旧稿は別コピーとして復元します。AIの回答や設定候補は作者が確認して使います。原稿を自動で置き換えたり、推測された設定を自動で確定したりする操作にはしていません。

サンプルから試す

  • 小説サンプル「雨の書店」：章、ルビ、縦中横、傍点・傍線を試せます。
  • 脚本サンプル：人物名、台詞、ト書きを試せます。

横書きの原稿へ読み取り専用の縦書き表示を添える場合は、プレビューを使います。Studioを使わず、M-x tategaki-editで縦書き編集だけを始めることもできます。

動作環境と追加機能

基本編集とStudioはEmacs Lispで動きます。パッケージの要件はEmacs 27.1以降で、主な実機検証はmacOSのEmacs 31.1です。ルビなどの組版表示にはSVG対応のGUI版Emacsと日本語フォントが必要です。

AIは既定で無効です。使う場合だけローカルLLMサーバーを設定します。辞書には既存のEmacs Lookup、音読にはmacOSのsay、ファイル出力にはDockerが必要です。各機能の要件と確認範囲は対応環境と制限を参照してください。

このマニュアルはリポジトリの現行実装に合わせた利用案内です。公開サイトと手元のコードに差がある場合は、手元のdocs/index.htmlを開いてください。
