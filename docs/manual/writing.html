CHAPTER 05

目次・執筆支援・校正

章と節を見渡しながら書く。字下げ、脚本、辞書、ルール検査。

原稿を書きながら章を移動し、会話文や脚本を整え、気になる表記を確認します。目次や検査結果は原稿とは別の画面に表示されます。本文の保存は C-x C-s、編集の取り消しは C-/ です。

初めて使う場合は はじめにから始めてください。移動・選択は 編集の基本、ルビ・禁則・版面は 組版と注記、表示や機能の設定は Studioと設定で説明します。

地の文と会話文を書く

縦書き編集を始めると、既定では執筆支援も有効になります。地の文を入力して RET を押すと、次の段落の先頭に全角空白を1字入れます。段落の先頭で 「 や 『 を入力すると、会話文用の字下げへ調整します。既定の会話文は字下げなしです。

# 第一章　雨上がり
　雨が止んだ。窓の外から鳥の声が聞こえる。
「もう出かけられるね。」
　私は傘を置き、玄関へ向かった。

空白だけの段落でさらに RET を押すと、その段落を空行として残します。C-u 2 RET でも区切りの空行を挟めます。現在の段落を揃えたいときは M-x tategaki-writing-indent-line を実行します。

この字下げは、原稿に実際の全角空白を挿入する編集です。新しい段落の入力を支援するもので、ファイルを開く、縦書きを始める、文章を貼り付けるだけで既存本文を一括整形することはありません。

字下げを調整する

執筆支援全体の切り替えは M-x tategaki-writing-mode です。細かい値は次の変数で設定できます。setq は既定値、原稿バッファでの setq-local はその原稿だけに使います。

変数既定値と働き
tategaki-writing-assistancet。縦書き開始時に執筆支援を有効にします。
tategaki-writing-auto-indentt。改行と会話文入力時の字下げを調整します。
tategaki-writing-paragraph-indent1。地の文の全角空白の数です。
tategaki-writing-dialogue-indent0。会話文の全角空白の数です。
tategaki-writing-dialogue-openers「『“‘。会話文の開始文字です。

見出しやシーンの行を通常の段落と同じように字下げしないための規則は、tategaki-writing-unindented-prefix-regexp です。独自の見出し記法を使う場合は、目次側の認識規則と併せて調整してください。

閉じ括弧を補う

執筆支援は Emacs の Electric Pair を使い、「」、『』、（）、［］、【】、〈〉、《》 の組を原稿バッファへ追加します。開き括弧を入力した後、補われた閉じ括弧の手前に本文を書けます。組の一覧は tategaki-writing-bracket-pairs で変更します。

Smartparensなど、既に別の括弧補完を使っている場合は、執筆支援を有効にする前に次を設定します。既に有効なら tategaki-writing-mode を一度切り、再度有効にしてください。

(setq tategaki-writing-electric-pair nil)

縦書き開始時に自動で有効にした執筆支援は、縦書き終了時に解除され、変更した括弧設定も戻ります。先に独立して有効にしていた執筆支援は残ります。

目次を開いたまま執筆する

Studio上部の [目次] をクリックすると、原稿にカーソルを残したまま右側へ章・節の一覧が開きます。Write中も開いておけます。もう一度 [目次] を押すと閉じます。キーでは C-c s o、コマンドでは M-x tategaki-studio-toggle-outline です。

Studioを使わない縦書き編集では C-c C-o または M-x tategaki-outline で開けます。この従来のコマンドは目次側へフォーカスを移します。

#第一章　雨上がり
　窓を開けた。
##第一節　駅へ
　傘を置いて家を出た。
# 第二章　待ち合わせ
　改札の前に、見慣れた姿があった。
# エピローグ

日本語の番号付き見出しは 第一章、第2節、第一幕、第2場 を認識します。Markdownの # 第一章 / ## 第一節、Orgの * 第一章 / ** 第一節 にも対応します。#第一章 / ##第一節 は空白なしで使えますが、任意のタイトルは # プロローグ のように空白を入れます。通常の #旅行 のようなハッシュタグは目次に入りません。

したいこと目次での操作
章の本文へ移動見出し名をクリック、またはその行で RET。
配下の節を隠す・開く見出し左の三角をクリック、または TAB。
手動で更新g。
目次を閉じる上部の [閉じる]、または q。

本文を移動すると現在の章・節が強調されます。折り畳んだ節の中を書いている間は、その節を含む見える親見出しを強調し、マウスを重ねると執筆位置の見出し名を表示します。見出しを追加・変更したときは、入力が一段落すると自動更新します。既定の待機時間は0.25秒です。

折り畳むのは目次だけです。原稿の段落を隠したり、章を並べ替えたりはしません。narrowingで編集範囲を限定している間は、その範囲の見出しだけを表示します。目次の表示状態は 前回の作業の再開にも引き継ぎます。

編集画面の目次と、提出用ファイルの見出し認識は別設定です。目次に出た見出しが、そのままPDFやEPUBの章になるとは限りません。出力の見出し設定も確認してください。

幅・位置・認識規則を変える

(setq tategaki-outline-width 30
      tategaki-outline-side 'right
      tategaki-outline-follow-point t
      tategaki-outline-heading-regexp 'auto)
;; 左側に置く場合は tategaki-outline-side を 'left にします。

tategaki-outline-heading-regexp を 'outline にすると、原稿のメジャーモードが設定する outline-regexp / outline-level を使います。独自の正規表現と tategaki-outline-level-function も指定できます。

一覧を開かず移動するには、M-x tategaki-outline-goto-heading で見出しを選びます。次・前へ移動するコマンドは tategaki-outline-next-heading / tategaki-outline-previous-heading です。

脚本・台本を書く

M-x tategaki-script-mode で脚本モードを始めます。これは text-mode 派生のメジャーモードで、既定では組版付き縦書きと入力支援を有効にします。シーン、人物名、台詞、ト書きを色と字下げで区別します。開始するだけで既存本文を整形することはありません。

第一幕
○ 居間・朝
太郎：
　　「おはよう。もう雨は止んだ？」
　（窓を開ける）
花子：
　　「ええ。駅まで歩けそうね。」

シーンから台詞まで入力する

  1. C-c C-s でシーン名を入力します。○ 居間・朝 のような行を挿入します。
  2. C-c C-d で人物名を入力します。人物名の行と台詞用の 　　「」 ができ、括弧内から書き始められます。
  3. C-c C-t でト書きを入力します。空欄で確定すると （） の中へ移ります。
  4. C-c C-o でシーン一覧を開き、見出しから移動します。
操作キーコマンド
シーンを挿入C-c C-stategaki-script-scene
人物名と台詞を挿入C-c C-dtategaki-script-dialogue
ト書きを挿入C-c C-ttategaki-script-stage-direction
現在の段落を字下げTABtategaki-script-indent-line
範囲・全文の字下げを揃えるC-c C-ftategaki-script-format
次・前のシーンへ移動M-n / M-ptategaki-script-next-scene / tategaki-script-previous-scene

人物名の段落末で RET を押すと、台詞用の字下げと括弧を用意します。人物名の入力では同じ原稿に出た名前を補完できます。本文での補完は M-TAB / C-M-i の completion-at-point を使い、Corfuが有効ならその候補一覧を利用します。

C-c C-f は、選択範囲があればその範囲にかかる段落、なければ現在編集できる範囲を整形します。変更するのは行頭の空白です。通常のUndoで戻せます。本文の TAB は字下げ、目次の TAB は折り畳みです。

脚本の字下げを変える

(setq tategaki-script-speaker-indent 0
      tategaki-script-dialogue-indent 2
      tategaki-script-stage-direction-indent 1
      tategaki-script-auto-dialogue t
      tategaki-script-start-vertical t)

数値は全角空白の数です。横書きで始めるなら tategaki-script-start-vertical を nil にします。人物名の次の括弧挿入は tategaki-script-auto-dialogue、自動字下げ全体は tategaki-writing-auto-indent で切り替えます。

シーンの挿入記号は tategaki-script-scene-prefix、認識規則は tategaki-script-scene-regexp です。変更する場合は両方を揃えます。人物名・台詞・ト書きの色は各 tategaki-script-…-face で調整できます。

終了方法と書式の範囲

C-c C-c は縦書き表示を終了します。脚本モード自体を終了するには M-x text-mode を実行します。既存のメジャーモードを保つ場合は、M-x tategaki-writing-set-style で script を選ぶ方法もあります。

長い台詞が画面の列末で折り返しても、継続列へ追加の字下げは入りません。放送局・劇団ごとの提出書式や独立した人物名欄は提供していません。出力では通常の原稿として扱い、脚本専用の印刷テンプレートにはなりません。

校正の指摘を確認する

M-x tategaki-proofread-run でローカルのルール検査を実行します。Studioの [校正] は指摘一覧を開く入口です。一覧の指摘をクリックすると本文の該当箇所へ移動し、縦書き本文上にも印を表示します。指摘を表示するだけで本文を修正することはありません。

検査対象には括弧の対応、約物の連続、全半角・数字表記、登録した表記揺れ・禁止語、文や段落の長さ、近くでの同じ語、語尾・助詞の連続、空白があります。長文は誤りとは限らないため、文脈を読んで採否を決めてください。

(setq-local tategaki-proofread-variants '(("出来る" . "できる")))
(setq-local tategaki-proofread-banned-words '("仮の名前"))

設定画面でリアルタイム校正を有効にすると、入力が一段落したときに変更箇所の近くを軽く検査します。既定では無効です。全原稿の検査とは対象範囲が違うので、推敲の区切りには手動検査も行ってください。

Review画面とレビュー一覧を使い分ける

上部の [Review] は推敲用のウィンドウ配置へ切り替えます。[Write] は原稿と表示中の目次を残し、推敲用の補助画面を閉じます。検査そのものを実行するボタンではありません。

[原稿] → [レビュー一覧]、または M-x tategaki-review は、校正・設定整合性・話し方・時系列・伏線・AI相談・音読・出力状態の入口をまとめた画面です。[原稿を検査] を押すと、ローカル校正、登録Factの比較、人物の話し方の検査を実行します。

設定や話し方の検査には、先に 人物・作品設定を登録します。レビュー画面を開くだけでAI送信や音読は始まりません。実行していない検査や出力を、完了したものとして扱うこともありません。

辞書を引く

[原稿] → [辞書]、C-c s d、または M-x tategaki-lookup-word で、既存のEmacs Lookupを使って調べます。検索語は選択範囲、カーソル位置の語、手入力の順に決めます。右側の見出し・本文ペインで結果を読み、原稿の位置を保ったまま調べられます。

Lookup本体と辞書の設定は別途必要です。未導入なら案内を表示します。Studioから開いた辞書一覧・見出し・本文・ヘルプ・項目情報には上部の [閉じる] があり、そのペインを閉じて原稿へ戻れます。
